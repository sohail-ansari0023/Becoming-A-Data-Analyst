## This file will contain _`cmd`_ prompt for the terminal

### To save the pakages detials in any file at the time of installation
- **Powershell:**
   - `pip install "package_name"; pip freeze > "file_name"`
- **CMD:**
   - `pip install "package_name" && pip freeze > "file_name"`

### To save all of the packages details from _`pip list`_
- **Powershell:**
    - `pip freeze > "file_name"`

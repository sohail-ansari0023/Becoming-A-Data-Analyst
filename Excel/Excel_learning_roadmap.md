## **Stage 1 — Beginner**

Learn the environment and understand how Excel handles data.

- Workbook, worksheets, rows, columns, cells.
- Data types: text, numbers, dates, percentages.
- Data entry and editing.
- Cell references: relative, absolute, mixed.
- Formatting and number formats.
- Basic mathematical formulas.
- SUM, AVERAGE, MIN, MAX, COUNT, COUNTA.
- Sorting and filtering.
- Excel Tables.
- Basic charts.

**Outcome:** We can organise and perform basic calculations on business data.

## **Stage 2 — Upper beginner**

Start developing analytical thinking.

- IF, IFS, AND, OR.
- SUMIF, SUMIFS.
- COUNTIF, COUNTIFS.
- AVERAGEIF, AVERAGEIFS.
- IFERROR.
- Text functions: LEFT, RIGHT, MID, LEN, TRIM, CLEAN.
- Date functions: TODAY, YEAR, MONTH, DAY, EOMONTH.
- Conditional formatting.
- Data validation and dropdown lists.
- Remove duplicates.
- Find and replace.

**Outcome:** We can clean moderately messy data and perform conditional calculations.

## **Stage 3 — Intermediate**

Start working like a junior analyst.

- XLOOKUP and VLOOKUP.
- INDEX and MATCH.
- Dynamic array functions: FILTER, SORT, UNIQUE.
- Advanced IF logic.
- Pivot Tables.
- Pivot Charts.
- Slicers and timelines.
- Advanced conditional formatting.
- Combining multiple functions.
- Data cleaning workflows.
- Introduction to Power Query.
- Business dashboards.
- Analytical reporting.

**Outcome:** We can independently analyse business datasets and communicate findings.

We will also introduce professional habits throughouot:

- Clear column names and consistent data types.
- No unneessary merged cells in analytical datasets.
- Avoid hardcoding values inside complex formulas.
- Build reusable and understandable formulas.
- Verify calculations before reporting results.
